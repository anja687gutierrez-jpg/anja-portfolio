About

I'm an operations coordinator turned full-stack developer. I build the tools my team actually needs, ship them to production, and maintain them myself. I don't work from templates — I architect systems from scratch using original research.

I own the full stack. Database schema, API design, frontend polish, deployment pipeline, DNS, SSL, monitoring. No handoffs.

I fix the root cause, not the symptom. I've debugged stale closures in React hooks, IndexedDB write-through races, cross-origin Worker issues, Babel Standalone transpilation edge cases, Stripe webhook signature failures, and Apple nanosecond timestamp decoding — all in production.

Zero-dependency by default. Ops Hub v2 is a 1.3 MB SPA that runs with no build step, no bundler, no Node.js — just CDN imports and a file server. When I reach for a framework it's because the project needs one.

AI-native workflow. I build in collaboration with Claude Code. I bring the domain expertise, product vision, and quality bar. Every commit is co-authored, because that's the honest truth of how modern software gets built.
